# E44 — Regímenes Especiales Electrónico

**TipoeCF:** 44  
**Clase:** `Ecf44Definition`  
**XSD:** `e-CF 44 v.1.0.xsd`  
**Estado DoD:** Completo

## Propósito

Comprobante para regímenes especiales (montos exentos de ITBIS). Canal e-CF individual (testecf).

## Campos obligatorios

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | TipoeCF, eNCF, FechaVencimientoSecuencia, TipoIngresos, TipoPago | |
| Comprador | RazonSocialComprador | RNC opcional |
| Totales | MontoTotal | MontoExento recomendado |
| Item | … IndicadorFacturacion(=4) … | Formato nota 50 |

## Campos opcionales

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | TablaFormasPago | |
| Comprador | RNCComprador, Correo, Dirección | |
| Totales | MontoExento | Si falta → MontoTotal |
| Item | DescuentoMonto, RecargoMonto, UnidadMedida | |
| Root | DescuentosORecargos | Permitido en XSD |

## Campos prohibidos

| Sección | Campo | Motivo |
|---------|-------|--------|
| IdDoc | IndicadorMontoGravado | No en XSD E44 |
| Totales | MontoGravado*, ITBIS* | No en XSD |

## Restricciones del XSD

- Tras FechaVencimiento: TipoIngresos y TipoPago obligatorios (sin IndicadorMontoGravado).
- Totales: MontoExento → (impuestos adicionales opc.) → MontoTotal.

## Reglas de negocio de la DGII

- `IndicadorFacturacion` = 4 (Exento) para 43/44/47.

## Restricciones y validaciones especiales

- Validar ítems con facturación 4; Totales sin ITBIS.
- Emisión fija IndicadorFacturacion=4.

## Casos especiales

- Contraste E43: E44 **sí** tiene Comprador, TipoIngresos y TablaFormasPago.
