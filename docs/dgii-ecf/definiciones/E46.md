# E46 — Comprobante de Exportaciones Electrónico

**TipoeCF:** 46  
**Clase:** `Ecf46Definition`  
**XSD:** `e-CF 46 v.1.0.xsd`  
**Estado DoD:** Completo

## Propósito

Exportación de bienes/servicios con ITBIS a tasa cero. Canal e-CF individual (testecf).

## Campos obligatorios

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | TipoeCF, eNCF, FechaVencimientoSecuencia, TipoIngresos, TipoPago | |
| Comprador | RNCComprador, RazonSocialComprador | RNC obligatorio en práctica DGII |
| Totales | MontoTotal (+ gravado I3 / ITBIS3) | |
| Item | IndicadorFacturacion(=3) | Formato nota 51 |

## Campos opcionales

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | TablaFormasPago | |
| Totales | MontoGravadoTotal, MontoGravadoI3, ITBIS3, TotalITBIS, TotalITBIS3 | |

## Campos prohibidos

| Sección | Campo | Motivo |
|---------|-------|--------|
| IdDoc | IndicadorMontoGravado | No en XSD |
| Totales | MontoGravadoI1/I2, ITBIS1/2, MontoExento, retenciones | No en XSD |

## Reglas de negocio de la DGII

- `IndicadorFacturacion` = **3** (ITBIS tasa cero).
- `RNCComprador` obligatorio en testecf aunque XSD diga `minOccurs=0`.

## Restricciones y validaciones especiales

- Validar ítems con facturación 3; RNC comprador; Totales solo familia I3.

## Casos especiales

- Contraste E44: E46 usa tasa cero (3), no exento (4).
