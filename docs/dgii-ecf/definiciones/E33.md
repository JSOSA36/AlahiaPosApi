# E33 — Nota de Débito Electrónica

**TipoeCF:** 33  
**Clase:** `Ecf33Definition`  
**XSD:** `e-CF 33 v.1.0.xsd`  
**Estado DoD:** Completo

## Propósito

Nota de débito que modifica un e-CF/NCF previo (p.ej. ajuste de montos). Requiere `InformacionReferencia`.

## Campos obligatorios

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | TipoeCF, eNCF, FechaVencimientoSecuencia, TipoPago | |
| InformacionReferencia | NCFModificado, FechaNCFModificado, CodigoModificacion | Sección `minOccurs=1` |
| Emisor / Totales / Items | Subconjunto común | |

## Campos opcionales

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | IndicadorMontoGravado, TipoIngresos, **TablaFormasPago** | TablaFormasPago **permitida** (≠ E34) |
| InformacionReferencia | RNCOtroContribuyente, RazonModificacion | |

## Campos prohibidos

| Sección | Campo | Motivo |
|---------|-------|--------|
| IdDoc | IndicadorNotaCredito | Solo E34 |
| Totales | MontoPropinaLegal | Fuera de XSD |

## Restricciones del XSD

- `InformacionReferencia` obligatoria; orden NCFModificado → … → CodigoModificacion.
- `FechaVencimientoSecuencia` obligatoria.
- `TablaFormasPago` opcional en IdDoc.

## Reglas de negocio de la DGII

- Referenciar NCF/e-NCF válido.
- `CodigoModificacion` según catálogo (1–5).

## Restricciones y validaciones especiales

- `RequiereInformacionReferencia = true` → falla local si falta `NCFModificado`.
- Contraste con E34: aquí **sí** se emite `TablaFormasPago` si viene en el DTO.

## Casos especiales

- En testecf se validó referenciando un E31 **Aceptado**.
