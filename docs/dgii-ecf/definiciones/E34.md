# E34 — Nota de Crédito Electrónica

**TipoeCF:** 34  
**Clase:** `Ecf34Definition`  
**XSD:** `e-CF 34 v.1.0.xsd`  
**Estado DoD:** Completo

## Propósito

Nota de crédito que anula o corrige un comprobante previo. Exige `IndicadorNotaCredito` e `InformacionReferencia`.

## Campos obligatorios

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | TipoeCF, eNCF | |
| IdDoc | IndicadorNotaCredito | 0 ≤30 días; 1 &gt;30 días del NCF modificado |
| IdDoc | TipoPago | |
| InformacionReferencia | NCFModificado, FechaNCFModificado, CodigoModificacion | |
| Emisor / Totales / Items | Subconjunto común | |

## Campos opcionales

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | IndicadorMontoGravado, TipoIngresos | TipoIngresos opcional en XSD; se emite |
| InformacionReferencia | RNCOtroContribuyente, RazonModificacion | |

## Campos prohibidos

| Sección | Campo | Motivo |
|---------|-------|--------|
| IdDoc | **TablaFormasPago** | **No está en XSD E34**; DGII rechaza con error XSD |
| IdDoc | FechaVencimientoSecuencia | No existe en XSD E34 |
| Totales | MontoPropinaLegal | Fuera de XSD |

Si el DTO trae `FormasPago`, el motor las **omite**.

## Restricciones del XSD

- Tras `eNCF`: `IndicadorNotaCredito` obligatorio (no FechaVencimiento).
- Secuencia IdDoc **sin** `TablaFormasPago`.
- `InformacionReferencia` `minOccurs=1`.

## Reglas de negocio de la DGII

- `IndicadorNotaCredito` según días desde el NCF modificado.
- Referencia a comprobante válido.
- Canal e-CF individual.

## Restricciones y validaciones especiales

- `IndicadorNotaCredito` debe ser 0 o 1 (default 0 si null).
- `TablaFormasPago` = `EcfCampoPresence.Prohibido` (omitir).
- `RequiereInformacionReferencia = true`.

## Casos especiales

- Contraste E33: misma familia “nota”, pero E34 **no** admite `TablaFormasPago`.
- Preview debe confirmar ausencia del nodo aunque el JSON lo envíe.
