# E47 — Comprobante para Pagos al Exterior Electrónico

**TipoeCF:** 47  
**Clase:** `Ecf47Definition`  
**XSD:** `e-CF 47 v.1.0.xsd`  
**Estado DoD:** Completo

## Propósito

Pagos al exterior con retención de ISR. Canal e-CF individual (testecf).

## Campos obligatorios

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | TipoeCF, eNCF, FechaVencimientoSecuencia | |
| Totales | MontoTotal | + TotalISRRetencion típico |
| Item | IndicadorFacturacion(=4), **Retencion** (MontoISRRetenido), NombreItem, IndicadorBienoServicio, Cantidad, Precio, MontoItem | Orden: Retencion antes de NombreItem |

## Campos opcionales

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | TipoPago, TablaFormasPago | |
| Comprador | IdentificadorExtranjero, RazonSocialComprador | Sección minOccurs=0; **sin RNCComprador**; MVP omite |
| Totales | MontoExento, TotalISRRetencion | |

## Campos prohibidos

| Sección | Campo | Motivo |
|---------|-------|--------|
| IdDoc | TipoIngresos, IndicadorMontoGravado | No existen en XSD E47 |
| Comprador | RNCComprador | No existe en XSD E47 |
| Item/Retencion | MontoITBISRetenido | No existe en XSD E47 |
| Root | DescuentosORecargos | No en XSD |

## Restricciones del XSD

- Tras `eNCF`: `FechaVencimientoSecuencia` obligatoria; **sin** `TipoIngresos` / `IndicadorMontoGravado`.
- `Comprador` opcional; si existe solo IdentificadorExtranjero + Razón (sin RNC).
- En cada `Item`, nodo `Retencion` **obligatorio** y **antes** de `NombreItem`.
- `Retencion.MontoISRRetenido` `minOccurs=1` (siempre emitir); **sin** `MontoITBISRetenido`.
- Totales: `MontoExento` + `MontoTotal` + `TotalISRRetencion` (sin ITBIS/gravados).

## Reglas de negocio de la DGII

- `IndicadorFacturacion` = 4 (Exento) — Formato nota 50 (tipos 43/44/47).
- Retención ISR por ítem sobre pagos al exterior.

## Restricciones y validaciones especiales

- `Comprador = null` en happy path (sección omitida).
- `RetencionItem(..., soloIsr: true)` — solo `MontoISRRetenido`.
- `Validar`: `IndicadorFacturacion=4`; `MontoTotal > 0`; `MontoISRRetenido ≥ 0`.
- `PermiteDescuentosORecargos = false`.

## Casos especiales

- Contraste E41: E47 no emite `MontoITBISRetenido`; Comprador sin RNC / omitible.
- Contraste E43/E44: E47 exige `Retencion` con ISR.
