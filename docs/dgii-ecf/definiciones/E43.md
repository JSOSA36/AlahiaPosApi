# E43 — Gastos Menores Electrónico

**TipoeCF:** 43  
**Clase:** `Ecf43Definition`  
**XSD:** `e-CF 43 v.1.0.xsd`  
**Estado DoD:** Completo

## Propósito

Comprobante de gastos menores (exento de ITBIS). Sin sección Comprador. Canal e-CF individual (testecf).

## Campos obligatorios

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | TipoeCF, eNCF, FechaVencimientoSecuencia | |
| Emisor | RNC, Razón social, Dirección, FechaEmision | |
| Totales | MontoTotal | MontoExento recomendado (= total) |
| Item | NumeroLinea, IndicadorFacturacion(=4), NombreItem, IndicadorBienoServicio, Cantidad, Precio, MontoItem | |

## Campos opcionales

| Sección | Campo | Notas |
|---------|-------|-------|
| IdDoc | TipoPago | |
| Totales | MontoExento | Si falta, el motor usa MontoTotal |
| Item | UnidadMedida | |
| InformacionReferencia | | minOccurs=0 |

## Campos prohibidos / omitidos

| Sección | Campo | Motivo |
|---------|-------|--------|
| Encabezado | **Comprador** (sección completa) | No existe en XSD E43 |
| IdDoc | TipoIngresos, IndicadorMontoGravado, TablaFormasPago | No en XSD |
| Totales | MontoGravado*, ITBIS*, retenciones | No en XSD |
| Root | DescuentosORecargos | No en XSD E43 |

## Restricciones del XSD

- Orden Encabezado: IdDoc → Emisor → **Totales** (sin Comprador).
- Totales: MontoExento → MontoTotal (+ opcionales periodo/saldo).
- Ítems sin DescuentoMonto / RecargoMonto / Retencion.

## Reglas de negocio de la DGII

- `IndicadorFacturacion` = **4 (Exento)** para tipos 43, 44 y 47 (Formato nota 50).
- Montos de gastos menores no son adelanto de ITBIS.

## Restricciones y validaciones especiales

- `Comprador = null` → el motor no emite la sección (extensión genérica del engine).
- `PermiteDescuentosORecargos = false`.
- `Validar`: todos los ítems con IndicadorFacturacion 4; MontoTotal &gt; 0.
- Emisión fija de IndicadorFacturacion=4 en Item.

## Casos especiales

- No RFCE.
- Motor: `IEcfTipoDefinition.Comprador` nullable (null = omitir sección) — aplica a futuros tipos sin comprador.
